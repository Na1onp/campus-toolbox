## 📖 项目简介

一个全栈 Web 应用，集成了 11 个校园生活常用工具，部署在腾讯云轻量应用服务器。

电脑端与手机端访问同一网址，自动呈现不同的 UI 布局。

**风格**：柔粉浅色 Soft UI（默认）+ 可选暗色模式
**国际化**：简体中文 / 繁体中文 / 英文
**合规**：所有数据源使用国内合规渠道

---

## ✨ 功能模块

### 核心 5 项
- 📚 **课程表** — 手动录入 + 教务系统导入，周/日视图，上课提醒
- 🏫 **空教室查询** — 按教学楼 / 节次 / 时段筛选
- 🗺️ **校园地图** — 静态平面图 + 标注点
- 🎓 **学院介绍** — 11 个学院卡片
- 🛏️ **宿舍介绍** — 宿舍楼卡片

### 扩展 6 项
- 📅 **校历/重要日期** — 开学、考试周倒计时
- 📰 **校园公告** — 抓取学校官网 RSS
- 🛒 **二手市场** — 同学间二手物品流转
- 📖 **学习资料共享** — 课件、笔记上传下载
- ☁️ **天气 + 穿衣建议** — 接入和风天气 API
- 💳 **一卡通余额（演示）** — 模拟查询

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Element Plus + Vant |
| 后端 | Node.js + Express + SQLite |
| 部署 | 腾讯云轻量应用服务器 + Nginx + PM2 |
| 版本管理 | Git + GitHub |

---

## 🚀 本地开发

```bash
# 安装依赖
pnpm install

# 启动前端
pnpm dev

# 启动后端
pnpm dev:server
```
